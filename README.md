# Rapha Google Ads Product Intelligence Dashboard

Interactive Streamlit dashboard for analysing Google Ads product-level performance.

## Features

- Product spend vs revenue analysis
- ROAS calculation
- Product efficiency comparison
- Campaign filters
- Budget recommendation engine

## Tech Stack

Python  
Streamlit  
Pandas  
Plotly

## Data Source

Google Ads exported campaign CSV data.

## Running Locally

Install dependencies:

pip install -r requirements.txt

Run the dashboard:

streamlit run app.py
